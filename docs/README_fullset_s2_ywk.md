## 2. 選了哪些交叉項

## 3. 每個 pair 的兩個點

- 都用 5%：每個 WC 取自己的 c_p（第 1 階段 5% 的值），或它的反號。
- **點**：(+c_p,i, ±c_p,j) 兩種正負號中 n_eff/N 較高的那組。
- **鏡像**：兩個 WC 都反號。c_i·c_j 不變（交叉項的訊號一樣），一次項反號；和第 1 階段的 ±c 一樣，讓 γ_ij 有冗餘，drop test 可以用。
- 更正：計畫 md 原本寫「選 a_ij·c_i·c_j < 0（交叉貢獻互相抵消）的方向，ESS 較高」，實際上不一定。交叉 yield 明顯不為 0（|yield| > 0.001）的 19 個中，有 12 個選中的方向交叉貢獻是正的；例如 cQj11×cQj31，抵消方向的 ESS 只有 0.10，另一個方向 0.82。原因大概是抵消時部分 events 的權重接近 0 或變負，權重分散變大。所以選點是直接比 ESS，不是看正負號。

## 5. 結果（2026-10-24）

### 訓練

162 個 jobs 全部完成（約 01:15），每個都有 model.pt。

### 最重要的發現：r ≤ 0 的根源是全域 fit 沒有加權

- `full_likelihood` 用沒有加權的 lstsq，所有網路的那一列權重一樣。四費米子網路的 misclosure 約 0.1–0.4（第 2 階段的交叉項網路中位數 0.15），SM_SM 只有 0.0004。
- 全部網路一起 fit 時，共用的 γ_sm 被雜訊大的網路拉走：per-event 的 γ_sm 和 SM_SM 網路本身的 ratio 差 rms **2.5**（r_SM 本身約 1）。
- 結果：ctGRe、ctGIm 不屬於任何四費米子網路，scan 卻壞掉（−6.6σ_t、−27σ_t，各約 1600 個 r ≤ 0 events）。
- 測試（用 cache，不改 repo）：把 SM_SM 那一列加權，γ_sm 回到 SM_SM 網路的值，r ≤ 0 消失：

  | SM 列權重 | rms(γ_sm − r_SMSM) | r ≤ 0 events：ctGRe / ctGIm / cQu1 / cQd8 |
  |---|---|---|
  | 1（現行） | 2.55 | 1659 / 1547 / 300 / 567 |
  | 10 | 0.22 | 129 / 104 / 0 / 4 |
  | 100 | 0.0023 | 0 / 0 / 0 / 0 |
  | 1000 | 0.0000 | 0 / 0 / 0 / 0 |

- **不是交叉項造成的**：第 1、2 階段 cache 的 sm、ctG 的 γ 幾乎一樣（差 rms < 1e-4）；只用第 1 階段 64 個網路一起 fit，ctG 的 scan 就已經一樣差。第 1 階段的 1D scan 看起來好，是因為每個 WC 只用自己的 4 個網路 + SM_SM 來 fit。
- 交叉項網路改變的是**四費米子的一次項**：鏡像點對 (c_i, c_j)、(−c_i, −c_j) 的差給出 lin_i·c_i + lin_j·c_j，和 1D 的 ±c 一起變成 overdetermined，交叉項網路的雜訊會分到一次項（例如 cQd1 的一次項，s2 − s1 rms 1.1，s1 本身 rms 0.9）。二次項幾乎不變。
